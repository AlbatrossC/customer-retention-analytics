# Model 1 v2 Data

This folder is the local data source for Model 1 v2.

Model 1 v2 should not depend on another model folder at runtime or training time.

## Files

```text
customers.csv
complaint_texts.json
responsiveness.csv
complaint_texts_with_customer_id.json
customers_model_1_v2.csv
```

`customers.csv` is the source monthly customer data for v2.

`complaint_texts.json` is the original complaint text pool.

`responsiveness.csv` is simulator support data. Do not use it for churn training.

`complaint_texts_with_customer_id.json` links complaint text to customer IDs. It is for Model 2 context, not Model 1 training.

`customers_model_1_v2.csv` is generated by the v2 feature builder.

## Commands

Create customer-linked complaint JSON:

```powershell
python model_1_v2\data\build_complaints_with_customer_id.py
```

Create v2 training features:

```powershell
python model_1_v2\training_scripts\xgboost_model1_v2\build_features.py
```
